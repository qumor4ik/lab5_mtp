## Описание заданий (Вариант 2)
В проекте реализовано десктопное GUI-приложение на базе `tkinter` и `ttk`, объединяющее все пять заданий варианта 2:
- **Средняя 2:** Окно с текстовым полем (`ttk.Entry`) и кнопкой (`ttk.Button`), выводящей введённый текст в метку (`TextInputFrame`).
- **Средняя 4:** Список (`tk.Listbox`) с полосой прокрутки, обработкой выбора элемента (`<<ListboxSelect>>`), добавлением и удалением записей (`ListboxFrame`).
- **Средняя 7:** Главное окно приложения с системным меню `File -> Exit` (горячая клавиша `Ctrl+Q`), пунктом сброса состояния и разделом `Help -> About` (`Lab5Application`).
- **Повышенная 2:** Рисование фигур мышью на холсте (`tk.Canvas`) с живым предпросмотром при перетаскивании (`<ButtonPress-1>`, `<B1-Motion>`, `<ButtonRelease-1>`), выбором фигуры (прямоугольник, овал, линия), выбором цвета и отменой действия (`DrawingCanvasFrame`).
- **Повышенная 6:** Программа «Конвертер валют» с поддержкой курсов `RUB`, `USD`, `EUR`, `CNY`, `KZT`, кнопкой смены направления конвертации (`⇄`), строгой валидацией суммы и историей операций (`CurrencyConverterFrame`).

## Структура проекта
- `logic.py` — бизнес-логика, модели данных и валидация входных параметров.
- `gui.py` — классы графического интерфейса на базе `tkinter` и `ttk`.
- `tests.py` — модульные автотесты (`assert`) для проверки логики и граничных случаев.
- `main.py` — точка входа: запуск автотестов, консольной демонстрации и главного окна GUI.
- `.gitignore` — правила игнорирования служебных файлов Python.
- `README.md` — документация проекта и инструкции по запуску.

## Запуск проекта

Запуск приложения с открытием графического окна:
```bash
python main.py
```

Запуск только автотестов и консольной демонстрации (без открытия окна):
```bash
python main.py --test
```
